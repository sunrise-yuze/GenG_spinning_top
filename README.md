# GEN.G 陀螺

把 Gen.G 队徽绕中轴转一圈，做成一个会自转、还能用鞭子抽的 3D 陀螺。

在线查看：https://sunrise-yuze.github.io/GenG_spinning_top/

水晶回转体里嵌着两片十字交叉的金色队徽：正对四个侧面时是完整的队徽，转快后残影叠出来的还是它。

## 抽陀螺

- 按住陀螺（或它身体两侧的空处），手里就多了一根鞭子；快速甩过陀螺，抽它一鞭，甩得越快力道越大
- 方向有讲究：从左往右抽，陀螺逆时针转（俯视）；从右往左抽，顺时针转
- 顺着当前转向抽是加速；逆着抽是减速，再抽就把它抽到反转
- 抽出来的速度很快会被摩擦磨掉，回到滑块设定的巡航转速，转向保持最后的方向
- 转速读数旁的小图标和底盘上跑动的光点显示当前转向
- 不想甩也行：点“◂抽 / 抽▸”按钮，或按方向键 ← →；空格键是顺着当前转向抽

## 其他操作

- 拖底盘（或陀螺以外的任何地方）换视角，滚轮或双指缩放
- 滑块设定巡航转速，拉到最左会停下并转到正对你的位置；滑块的填充段显示当前实际转速
- “正侧面”按钮切到纯侧视
- 右上角可以关掉音效
