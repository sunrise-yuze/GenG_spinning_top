# GEN.G 陀螺

把 Gen.G 队徽绕中轴转一圈，做成一个会自转的 3D 陀螺。

在线查看：https://sunrise-yuze.github.io/GenG_spinning_top/

## 三种形态

| 形态 | 从侧面看到什么 |
|---|---|
| 水晶 | 水晶回转体里嵌两片十字交叉的金色队徽。正对四个侧面时是完整队徽，转快后残影叠成队徽。 |
| 纯金 | 实心金陀螺，任何角度的外轮廓都是队徽。 |
| 剖面 | 朝向你的一半变成水晶，截面始终是完整队徽。 |

## 操作

- 拖动换视角，滚轮缩放
- 滑块调转速，拉到“停”会自动转到正对你的位置
- “正侧面”按钮切到纯侧视
