# 队徽陀螺：GEN.G 与 TES

把战队队徽绕中轴转一圈，做成能用鞭子抽的 3D 陀螺。现在有两台，可以切换：

- **GEN.G**：金色，五边形轮廓
- **TES**：红色，六边形盾牌里一个 T 形镂空

每台都有两种外观，用“水晶”按钮切换：

- **水晶开**：透明水晶外壳配抛光金属队徽，有反光（GEN.G 默认）
- **水晶关**：磨砂纯色外壳配哑光队徽，没有反光，接近队徽的平面效果（TES 默认）

在线查看：https://sunrise-yuze.github.io/GenG_spinning_top/

每台陀螺都是同一个做法：队徽半边绕中轴转一圈得到的回转体，里面嵌着两片十字交叉的队徽。正对四个侧面时是完整的队徽，转快后残影叠出来的还是它。

## 抽陀螺

- 按住陀螺（或它身体两侧的空处），手里就多了一根鞭子；快速甩过陀螺，抽它一鞭，甩得越快力道越大
- 方向有讲究：从左往右抽，陀螺逆时针转（俯视）；从右往左抽，顺时针转
- 顺着当前转向抽是加速；逆着抽是减速，再抽就把它抽到反转
- 没有马达：不抽它，摩擦会让它一直慢下来，直到停住并转到正对你的位置
- 转速读数旁的小图标和底盘上跑动的光点显示当前转向
- 不想甩也行：点“◂抽 / 抽▸”按钮，或按方向键 ← →；空格键是顺着当前转向抽

## 其他操作

- 底部左侧的“GEN.G / TES”切换陀螺，页面配色跟着换
- 拖底盘（或陀螺以外的任何地方）换视角，滚轮或双指缩放
- 滑块就是转速表：滑块位置是当前实际转速；也可以直接拖它设定转速，按住时保持，松手后照常减速
- “正侧面”按钮切到纯侧视
- “水晶”按钮开关透明水晶外壳，两台陀螺各自记住自己的选择
- 右上角可以关掉音效
